# ResearchAgent v0.4 验收报告

## 1. v0.4 状态

v0.4 已完成并通过本地验收。系统保持 v0.3 架构，只做增量开发：Reviewer 从“定位问题”扩展为“提供需人工批准的保守修订建议”，并新增文献变更历史、PDF 页级质量、analysis provenance 扩展、审计日志和同步运行历史。

## 2. 已完成能力

- Reviewer `sentence_issues[]` 新增 `revision_diff`，字段由 `services/api/app/tools/revision_diff.py` 生成，并由 `services/api/app/agents/reviewer_agent.py` 写入 `reviews/review_report.json`。
- 修订决策 API 已实现：`services/api/app/api/review.py` 写入 `reviews/revision_decisions.jsonl`，且 `applied_to_manuscript=false`。
- 文献 metadata PATCH 历史已实现：`services/api/app/api/literature.py` 调用 `services/api/app/tools/metadata_history.py` 写入 `literature/metadata_history.jsonl`。
- PDF 页级质量与 OCR 预留字段已实现：`services/api/app/tools/pdf_parser.py` 输出 `pages[]` 和 `ocr_status="not_configured"`。
- Analysis provenance v0.4 已实现：`services/api/app/tools/analysis_provenance.py` 输出 parameters、script_version、random_seed、output_file_hashes。
- 最小审计日志已实现：`services/api/app/tools/audit_log.py` 写入 `audit/audit_log.jsonl`。
- 任务运行历史已实现：`services/api/app/tools/run_history.py` 写入 `runs/run_history.json`。
- 前端新增 v0.4 详情面板：RevisionDiff、LiteratureHistory、PDFQuality、AuditLog、RunHistory，并保留 mock fallback。

## 9. 当前未完成能力

- v0.4 不自动把 revision_diff 应用到 manuscript。
- v0.4 不执行真实 OCR。
- v0.4 不做真实 DOI 联网核验。
- v0.4 不做统计显著性检验、p 值或因果推断。
- v0.4 不做登录、多租户、公网生产部署、队列化或数据库迁移。

## 10. 启动方式

后端：

```bash
cd services/api
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

前端：

```bash
cd apps/web
npm run dev -- --hostname 127.0.0.1 --port 3000
```

v0.4 demo：

```bash
python scripts/seed_demo.py
python scripts/run_demo.py
python scripts/validate_v04.py
```

## 11. v0.5 建议方向

- 把 accepted revision decision 转为人工确认后的 manuscript patch 草稿，但继续禁止自动提交。
- PDF OCR fallback 接入前先完成 OCR 质量门禁与人工确认界面。
- 审计日志增加哈希链或签名，避免被误认为生产级审计。
- 引入更完整的真实后端 Playwright E2E。
- 评估登录、多租户、PostgreSQL、队列等生产化基础能力，但不作为 v0.4 范围。
