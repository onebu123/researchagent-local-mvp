# ResearchAgent v0.8 验收报告

## 1. 版本状态

ResearchAgent v0.8 已在 v0.7 基线上完成增量开发并通过验收。v0.8 没有重写架构，没有引入登录、多租户、PostgreSQL、Redis、Celery、LangGraph、公网部署、真实 DOI 核验、真实 OCR、真实科研软件或真实湿实验仪器。

v0.8 的定位是把 v0.7 的 safe merge、version lineage、issue human review 链路扩展为更细粒度的修订 diff、metadata 字段审阅、PDF/analysis 质量报告，以及更可用的本地审计和运行历史。

## 2. v0.8 已完成能力

- Line-level / sentence-level revision diff：新增 `services/api/app/tools/revision_line_diff.py`，输出 `manuscript/revision_diffs/revision_diff_*.json`，记录 section、paragraph、sentence、line_start、line_end、before、after、related_issue_ids、related_claim_ids 和 safety_status。
- Literature metadata field diff：新增 `services/api/app/tools/literature_metadata_diff.py`，输出 `literature/metadata_diff_report.json`，提供字段级 old/new diff 和 revert suggestion。
- Literature metadata batch review：输出 `literature/metadata_review_batch.json`，统计 placeholder/extracted/verified 并给出 manual_review_required/no_action 等建议。
- PDF page quality report：新增 `services/api/app/tools/pdf_quality_report.py`，输出 `literature/pdf_quality_report.json`，包含 low_quality_pages、suspected_scanned_pages、issue_categories 和 OCR not configured 分类。
- Analysis provenance comparison：新增 `services/api/app/tools/analysis_compare.py`，输出 `analysis/comparisons/analysis_compare_*.json`，比较 parameters、input hash、output hash、runtime、warnings、limitations。
- Audit event classification：扩展 `services/api/app/tools/audit_log.py`，新增 event_category、risk_level、entity_type、entity_id，hash chain 验证继续通过。
- Run history diagnostics：扩展 `services/api/app/tools/run_history.py`，新增 failure_diagnostics、recoverable、retry_hint，不引入队列，不自动重试。
- 前端新增 v0.8 面板并保留 mock fallback：RevisionLineDiffPanel、LiteratureMetadataDiffPanel、LiteratureMetadataBatchPanel、PDFQualityReportPanel、AnalysisComparePanel。
- Playwright E2E 增强：新增 `apps/web/e2e/v08-quality-diff.spec.ts`，覆盖 v0.8 新面板、Audit classification 和 Run diagnostics 的 mock fallback 渲染。

## 3. v0.8 仍未完成能力

- 不做真实 OCR，只标记 OCR not configured 和疑似扫描页。
- 不做真实 DOI、作者、年份、期刊、页码联网核验。
- 不自动执行 metadata revert suggestion。
- 不自动把 placeholder/extracted 文献变成 verified。
- 不做真实分析运行历史对比的外部实验复现，只比较已有 provenance 文件。
- 不做登录、多租户、权限系统、生产审计系统或公网部署。
- 不做真实队列、自动重试或后台任务调度。
- 不做完整 LaTeX 编译、真实查重或绕过 AI 检测。

## 8. 数据结构说明

Revision line diff：

- 输出：`projects/{project_id}/manuscript/revision_diffs/revision_diff_*.json`
- 核心字段：revision_diff_id、base_file、target_file、created_at、summary、changes。
- change 字段：change_id、section、paragraph_index、sentence_index、line_start、line_end、before、after、change_type、related_issue_ids、related_claim_ids、safety_status、notes。

Literature metadata diff：

- 输出：`projects/{project_id}/literature/metadata_diff_report.json`
- 核心字段：generated_at、records。
- change 字段：field、old_value、new_value、change_type、source_history_id、revert_suggestion。
- revert suggestion 仅返回建议，不修改 `literature_index.json`。

Metadata batch review：

- 输出：`projects/{project_id}/literature/metadata_review_batch.json`
- 核心字段：batch_id、created_at、summary、records。
- record 字段：literature_id、title、metadata_status、human_verified、recommended_action、reasons。
- placeholder 文献推荐 `manual_review_required`；verified 且 human_verified=true 文献推荐 `no_action`。

PDF quality report：

- 输出：`projects/{project_id}/literature/pdf_quality_report.json`
- 核心字段：generated_at、pdfs、summary。
- PDF record 字段：source_file、metadata_file、quality_label、quality_score、page_count、low_quality_pages、empty_pages、suspected_scanned_pages、issue_categories、recommended_action、ocr_attempted。
- OCR 只预留，不执行。

Analysis comparison：

- 输出：`projects/{project_id}/analysis/comparisons/analysis_compare_*.json`
- 核心字段：comparison_id、base_provenance、target_provenance、created_at、summary、diffs。
- diffs 包含 parameters、input_data_hash、output_file_hashes、runtime、warnings、limitations。

Audit event classification：

- 输出：`projects/{project_id}/audit/audit_log.jsonl`
- 新字段：event_category、risk_level、entity_type、entity_id。
- 事件分类不构成权限系统；hash chain 仍由 prev_hash/entry_hash 校验。

Run history diagnostics：

- 输出：`projects/{project_id}/runs/run_history.json`
- 新字段：failure_diagnostics、recoverable、retry_hint。
- 成功 run 也保留 diagnostics 空结构；失败 run 记录 failed_step、likely_cause 和 suggested_recovery。

## 16. v0.8 为什么仍不适合公网生产

- 没有登录、鉴权、多租户隔离或权限系统。
- audit log 是本地完整性辅助链，不是生产级不可篡改审计。
- run history 不包含真实任务队列、重试调度或分布式状态管理。
- PDF OCR、DOI 核验、引用数据库、真实科研软件和真实实验仪器均未接入。
- mock fallback 和 demo 数据仍是本地 MVP 能力，不代表生产可信来源。
- 文件存储仍为本地项目目录，不适合多人并发、公网暴露或敏感数据托管。

## 17. v0.9 建议方向

- Revision diff reviewer：对每个 line/sentence change 生成更明确的人工确认状态和修订说明。
- Metadata review workflow：把 field diff、batch review 和人工确认记录形成可追踪审阅流。
- PDF parse quality UI：按页展示 parsed text 质量、疑似扫描页和人工复核状态。
- Analysis comparison timeline：在 run history 中关联多次 analysis comparison。
- Audit report filters：按 event_category、risk_level、entity_type 导出更细的本地审计报告。
- Playwright real backend coverage：继续扩大真实后端路径，覆盖 v0.8 新 API 的失败分支和边界保护。
