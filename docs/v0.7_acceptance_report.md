# ResearchAgent v0.7 验收报告

## 1. v0.7 完成能力清单

- Safe Merge Confirmation：merge preview 必须通过 API/前端显式确认或拒绝，确认后生成新 manuscript version，不覆盖 `manuscript/draft.md`。
- Merge-generated Manuscript Version：确认 merge 后生成 `manuscript/versions/manuscript_v*.md`，并在 `version_history.json` 中记录 `source_type="merge"`、`source_merge_id`、`source_patch_ids`、`source_decision_ids`、`source_issue_ids`。
- Merge-generated Diff：确认 merge 后自动生成 `manuscript/diffs/diff_*.json` 和 `.md`。
- Version Lineage：新增 `manuscript/versions/version_lineage.json`，记录 draft、patch、merge、version、diff、issue_resolution 的节点与边。
- Patch Conflict 详情增强：conflict item 增加 `related_claim_id`、`item_status`、`latest_safety_result`、`safety_blocked_reasons`，conflict 增加 `suggested_resolution`。
- Issue Resolution Human Review：新增 `reviews/issue_resolution_reviews.jsonl`，记录 `auto_status` 与 `human_status`，并在 `issue_resolution.json` 中展示 human review summary。
- Audit File Manifest：audit export 后生成 `audit/exports/audit_file_manifest_*.json`，记录输出文件相对路径、分类、大小与 SHA256。
- 前端 v0.7 面板：Patch Merge 支持 confirm/reject，Version Lineage 可查看节点/边，Issue Resolution 可人工标记，Audit Export 可查看 manifest 摘要。
- v0.7 测试与验证：新增后端测试、`scripts/validate_v07.py`、Playwright E2E。

## 2. 仍未完成能力清单

- 不做登录、多租户、权限系统、公网部署。
- 不做 PostgreSQL、Redis、Celery、LangGraph 迁移。
- 不做真实 DOI 联网核验、真实 OCR、真实科研仪器接入、真实查重。
- 不做自动语义证明：issue resolution 的自动状态只代表 provenance 关系。
- 不做生产级防篡改审计：audit manifest/hash chain 仍是本地完整性辅助。

## 6. v0.7 数据结构

- `manuscript/patches/merges/merge_*.json`：新增 `confirmed_at`、`rejected_at`、`generated_version_id`、`generated_diff_id`、`confirmed_reason`、`rejected_reason`。
- `manuscript/versions/version_history.json`：merge version 记录 `source_type="merge"`、`source_merge_id`、`source_patch_ids`、`source_decision_ids`、`source_issue_ids`。
- `manuscript/versions/version_lineage.json`：包含 `nodes[]`、`edges[]`、`summary`、`warnings`。
- `reviews/issue_resolution_reviews.jsonl`：每条记录包含 `review_id`、`issue_id`、`version_id`、`auto_status`、`human_status`、`reason`、`created_at`、`source`。
- `audit/exports/audit_file_manifest_*.json`：包含 `file_count`、`category_counts`、`files[]`，文件记录含 `relative_path`、`category`、`size_bytes`、`sha256`。

## 13. v0.8 建议方向

- Reviewer sentence issue 精确修订 diff：把 sentence issue 与可执行 diff 的范围进一步收窄到行级/句级。
- Literature metadata 变更历史增强：增加字段级 diff、撤销建议和批量审阅。
- PDF 页级质量报告增强：加入 OCR fallback 预留检查，但仍不强制联网或生产 OCR。
- Analysis provenance 参数增强：记录脚本版本、运行参数、随机种子和环境指纹的更细粒度差异。
- 真实后端 Playwright E2E：继续扩大基于真实 FastAPI 的端到端链路。
- 最小审计日志增强：增加关键用户操作的更细粒度事件分类。
- 任务运行历史增强：展示 patch/merge/review/audit export 的运行历史和失败恢复信息。
