# ResearchAgent v1.4 Acceptance Criteria

v1.4 的目标是在 v1.3 本地 RAG 质量能力之上，新增 Statistical Assistant（统计分析助手）。它只基于本地 CSV 描述统计产物生成数据健康检查、变量角色建议、描述统计卡、相关性审查和方法建议，不生成 p-values、statistical significance、causal inference 或真实实验结论。

## Scope

- 新增 `services/api/app/tools/statistical_assistant.py`。
- 新增输出：
  - `analysis/statistical_assistant_report.json`
  - `analysis/statistical_assistant_notes.md`
- 新增 API：
  - `GET /api/projects/{project_id}/analysis/statistical-assistant`
  - `POST /api/projects/{project_id}/analysis/statistical-assistant/generate`
- 新增前端面板：
  - `apps/web/components/StatisticalAssistantPanel.tsx`
  - Dashboard `Analysis` 分组中的 `Statistical Assistant` 入口
- 新增验证：
  - `services/api/tests/test_v14_statistical_assistant.py`
  - `services/api/tests/test_v14_no_inference_claims.py`
  - `services/api/tests/test_v14_no_network_required.py`
  - `apps/web/e2e/v14-statistical-assistant.spec.ts`
  - `scripts/validate_v14.py`

## Functional Acceptance

1. `python scripts/run_demo.py` must generate `analysis/statistical_assistant_report.json` and `analysis/statistical_assistant_notes.md`.
2. The report must include dataset shape, numeric/categorical columns, missingness, constant/near-constant checks, IQR outlier flags, variable role suggestions, descriptive cards, association candidates, method suggestions, guardrails, and limitations.
3. Variable role suggestions must be advisory only, using terms such as `id-like`, `numeric`, `categorical`, `outcome-candidate`, and `predictor-candidate`.
4. Correlation output must be labeled as association candidates only and must not be described as causal evidence.
5. Method suggestions may mark inferential statistics as blocked or requiring a human protocol, but v1.4 must not compute or report p-values.
6. The GET API must return a clear 404 when the project or report file is missing.
7. The POST API must generate the local report from existing `analysis/result_summary.json` and `analysis/processed_data.csv`.
8. All paths in API responses and reports must be project-relative paths only.
9. The frontend panel must render with mock fallback when backend API requests fail.
10. `validate_v14.py` must pass without API key or external network dependency.

## Safety Acceptance

- Do not fabricate DOI, references, p-values, statistical significance, causal relationships, experimental conclusions, peer-review-ready status, or production-ready status.
- Do not treat demo data as real experimental data.
- Do not submit API keys, secrets, `.env*`, runtime build output, Playwright reports, or project runtime data.
- Do not overwrite `manuscript/draft.md`.
- Preserve v1.1, v1.2, and v1.3 validation.
