# ResearchAgent v2.0 Acceptance Report

Status: implemented and verified locally on 2026-06-08.

## Delivered

- Production scaffold status API: `GET /api/system/production-scaffold`.
- Optional scaffold configuration in `services/api/app/config.py`.
- Worker scaffold smoke entrypoint: `python -m app.workers.research_worker`.
- Frontend Research Workspace scaffold panel.
- Dockerfiles for API and web plus optional compose profiles for PostgreSQL, queue, and worker.
- Deployment guide: `docs/deployment_v2.md`.
- Validation script: `scripts/validate_v2.py`.

## Results

- Default local mode remains SQLite, inline queue, disabled auth, and mock LLM fallback.
- The scaffold API reports configuration presence and fallback state without returning secret values.
- The frontend shows optional database, queue, auth, container, worker, and validation state even when backend API calls are blocked.
- PostgreSQL, queue, and auth are optional scaffolds; they are not mandatory for local demo validation.
- Local CORS origins are configurable through `CORS_ALLOW_ORIGINS`; validation uses an explicit localhost allowlist for isolated Playwright ports.

## Verification Results

The following local commands passed:

- `python -m pytest services\api\tests\test_v2_production_scaffold.py`
- `python -m pytest services\api\tests\test_v2_static_contract.py`
- `python -m pytest services\api\tests\test_v2_validate_audit_fallback.py`
- `python -m app.workers.research_worker`
- `npm run typecheck`
- `npx playwright test -g "v2.0 Research Workspace scaffold"`
- `python scripts\validate_v1.py`
- `python scripts\validate_v2.py`

`scripts/validate_v2.py` also reruns the v1.6 validation chain before checking v2 files, API markers, docs, Docker scaffold, frontend markers, and safety guardrails.
During local no-network runs, `npm audit` is allowed to report a skipped network-only audit with an explicit message. Real vulnerability reports are still blocking and must be fixed or documented before release.

## Known Limits

- v2.0 is a scaffold and local validation milestone.
- Auth is disabled by default and must be enforced server-side before shared use.
- PostgreSQL and queue modes require operator configuration and review.
- The deployment guide is a planning artifact, not a hosted environment proof.
- The scaffold does not validate scientific truth, compliance status, or review outcome.
