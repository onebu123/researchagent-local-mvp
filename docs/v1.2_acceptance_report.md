# ResearchAgent v1.2 验收报告

## 范围

v1.2 在 v1.1 Literature Intelligence 基础上实现 Reference Verification & Citation Grounding 增量能力。实现保持本地 MVP 边界：默认 `mock_fixture`，无 API key、无外部网络依赖，不引入登录、多租户、生产队列、真实 OCR、真实 DOI 数据库或 peer-review-ready 声明。

## 已实现能力

- Reference Verification：生成 `literature/reference_verification/reference_verification_results.jsonl` 与 `reference_verification_summary.json`。
- Match Score：计算 title、author、year、DOI、journal 与 overall confidence；DOI mismatch 降低 confidence，缺失 DOI 不会被伪造。
- Approval Workflow：生成 `literature/reference_approvals.jsonl` 与 `reference_approval_summary.json`；默认 `apply_to_literature_index=false`。
- 显式 apply：仅 `decision=approved` 且 `apply_to_literature_index=true` 时写回 `literature_index.json`，并记录 `literature/metadata_history.jsonl` 与 `audit/audit_log.jsonl`。
- Citation Grounding：生成 `provenance/citation_grounding_report.json`，每条 claim 绑定本地 candidate chunk、signals 与 grounding strength。
- Manuscript References：生成 `manuscript/references_status.json` 与 `manuscript/references_section_preview.md`，不覆盖 `manuscript/draft.md`。
- BibTeX upgrade：正式 BibTeX entry 只来自 `metadata_status=verified`、`human_verified=true`、`reference_verification_status=approved` 的记录。
- Frontend：新增 `ReferenceVerificationPanel`、`ReferenceApprovalPanel`、`CitationGroundingPanel`、`VerifiedReferencesPanel`，并扩展 Metadata Lookup、BibTeX、Citation Support、Global Trust Dashboard。

- `GET /api/projects/{project_id}/literature/reference-approval-summary`

- `GET /api/projects/{project_id}/manuscript/references/preview`

## 安全与不伪造规则

- verification candidate 不会自动修改 `literature_index.json`。
- approval 默认不 apply；`apply_to_literature_index=true` 必须显式传入。
- rejected、needs_manual_check、candidate、placeholder 不进入正式 References 或正式 BibTeX entry。
- 系统不伪造 DOI、作者、年份、期刊、页码、p 值、统计显著性、因果关系或真实实验结论。
- Citation Grounding 只表示本地 passage grounding，不证明科学事实或同行评审通过。
