# ResearchAgent v1.6 Acceptance Criteria

ResearchAgent v1.6 is a UX consolidation release for the local Research Workspace dashboard. It does not add production deployment, authentication, external citation verification, or new scientific claims.

## Scope

1. Add a first-screen `Workspace Readiness` panel that summarizes runtime mode, workflow state, trust status, and export availability.
2. Keep mock fallback visible and usable when the backend or external network is unavailable.
3. Keep Global Trust, RAG Quality, Statistical Assistant, and Workspace Export as explicit human-review actions.
4. Preserve the existing dashboard plus drawer interaction model.
5. Add Playwright coverage for the v1.6 panel and core action routing.
6. Add static pytest coverage that verifies v1.6 does not introduce backend routes, direct browser fetches, unsafe HTML rendering, or secret markers.
7. Add `scripts/validate_v16.py`.

## Guardrails

- Do not add login, auth, tenancy, PostgreSQL, Redis, queues, public deployment, or cloud assumptions in v1.6.
- Do not fabricate DOI, citations, p-values, significance, causal claims, OCR output, or scientific conclusions.
- Do not claim production, compliance, or peer-review readiness.
- Do not submit secrets, API keys, local absolute paths, stack traces, or environment file contents.
- Keep demo usable with no API key and no external network.

## Required Validation

```bash
python -m pytest services\api\tests\test_v16_ux_static_contract.py
python scripts\validate_v16.py
cd apps\web
npm run typecheck
npx playwright test -g "v1.6 UX consolidation"
```

`ResearchAgent v1.6 validation passed.` must be printed by the v1.6 validation script.
