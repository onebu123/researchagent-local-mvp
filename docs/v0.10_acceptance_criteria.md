# ResearchAgent v0.10 验收标准

## 范围

v0.10 是在 v0.9 基础上的增量版本，目标是把人工证据复核、全局 trust 汇总、reviewer issue 闭环、metadata revert 预览、PDF 页文本预览、analysis timeline 失败诊断、失败 fixture 和 v1.0 local MVP readiness 报告串成可审计链路。

## 必须满足

- Evidence claim review 只能写入 `provenance/evidence_claim_reviews.jsonl` 和 `provenance/evidence_claim_review_summary.json`，不得自动修改 `provenance/evidence.json`。
- Global Trust Dashboard 必须聚合 evidence claim review、revision diff review、metadata review action、PDF page review、reviewer closure、audit hash chain、run failure diagnostics 和 placeholder literature 风险。
- Reviewer Closure 只能根据 reviewer sentence issue、revision diff change 与最新 human revision diff review 判断工作流闭环；不得宣称语义问题已被系统自动证明解决。
- Metadata Revert Preview 只能输出预览 JSON，必须包含 `applied=false` 和 `literature_index_modified=false`，不得修改 `literature/literature_index.json`。
- PDF Page Text Preview 只能使用已有 parsed text / metadata，必须明确 `ocr_attempted=false`，不得执行 OCR。
- Enhanced Analysis Timeline 必须展示 comparison change summary 与 failed run diagnostics，并能识别 `run_failure_fixture_001`。
- Run History Failure Fixture 必须可重复生成，且不会重复追加同一个 fixture run。
- v1.0 Readiness Report 只能表示 local MVP readiness；不得输出或暗示 production-ready、compliance-ready 或 peer-review-ready。
- 前端必须新增并暴露以下 mock fallback 面板：Evidence Claim Review、Global Trust Dashboard、Reviewer Closure、Metadata Revert Preview、PDF Page Text Preview、v1.0 Readiness。
- `scripts/validate_v10.py` 必须串行运行 v0.9 验证、v0.10 API/产物检查和前端 typecheck。

## 禁止事项

- 不引入登录、多租户、权限系统、PostgreSQL、Redis、Celery、LangGraph、公网部署、真实 DOI 验证、真实 OCR、真实科研软件/仪器集成或查重能力。
- 不伪造 DOI、作者、年份、期刊、页码、p 值、统计显著性、因果关系、真实实验结论或 verified references。
- 不在 audit export、trust summary 或 readiness report 中泄露 secret、API key、内部绝对路径或堆栈。
