# ResearchAgent v1.5 Acceptance Criteria

ResearchAgent v1.5 adds Workspace Export for local Word, LaTeX, and trust-report artifacts. It does not change the project into a production, compliance, or peer-review system.

## Scope

1. Generate `exports/workspace/research_workspace_export.docx` from local manuscript, trust, reference, citation-grounding, analysis, and audit artifacts.
2. Generate `exports/workspace/research_workspace_export.tex` as LaTeX source only. Full LaTeX compilation is out of scope.
3. Generate `exports/workspace/trust_report.md` and `exports/workspace/trust_report.json`.
4. Generate `exports/workspace/workspace_export_manifest.json` with project-relative paths, artifact hashes, source-file availability, safety status, warnings, and caveats.
5. Add API endpoints:
   - `POST /api/projects/{project_id}/export/workspace`
   - `GET /api/projects/{project_id}/export/workspace`
6. Add Workspace Export dashboard panel with mock fallback.
7. Add `scripts/validate_v15.py`.

## Guardrails

- Do not include API keys, secrets, full local absolute paths, stack traces, or private environment files.
- Do not fabricate DOI, authors, year, journal, references, p-values, significance, causal claims, OCR output, or scientific conclusions.
- Do not promote candidate or placeholder references to formal references.
- Do not claim production, compliance, or peer-review readiness.
- Keep validation runnable with no API key and no external network dependency.
