# ResearchAgent v1.4 Acceptance Report

Status: passed.

v1.4 adds Statistical Assistant as a local descriptive analysis helper. It is not an inferential statistics engine and does not generate p-values, statistical significance claims, causal inference, real experimental conclusions, production-ready claims, or peer-review-ready claims.

## Completed

- Backend tool:
  - `services/api/app/tools/statistical_assistant.py`
  - Generates `analysis/statistical_assistant_report.json`
  - Generates `analysis/statistical_assistant_notes.md`
- Workflow integration:
  - `services/api/app/agents/analysis_agent.py`
  - The analysis step registers v1.4 Statistical Assistant outputs.
- API:
  - `GET /api/projects/{project_id}/analysis/statistical-assistant`
  - `POST /api/projects/{project_id}/analysis/statistical-assistant/generate`
- Frontend:
  - `apps/web/components/StatisticalAssistantPanel.tsx`
  - Dashboard `Analysis` entry: `Statistical Assistant`
  - Typed API and mock fallback in `apps/web/lib/api.ts`
  - Report types in `apps/web/lib/types.ts`
- Tests:

## Not Completed By Design

- No p-values.
- No statistical significance testing.
- No causal inference.
- No automatic manuscript rewrite.
- No external network or API key requirement.
- No real experimental conclusion, production-ready claim, compliance-ready claim, or peer-review-ready claim.
