# ResearchAgent v0.9 验收报告

## 1. 版本状态

ResearchAgent v0.9 已在 v0.8 基线上完成增量开发并通过验收。v0.9 没有重写架构，没有引入登录、多租户、PostgreSQL、Redis、Celery、LangGraph、公网部署、真实 DOI 核验、真实 OCR、真实科研软件或真实仪器。

v0.9 的定位是把 v0.8 的 revision diff、metadata diff、PDF quality、analysis compare、audit classification 和 run diagnostics 继续推进为可追踪的人工审阅工作流。

## 4. v0.9 已完成能力

- Revision Diff Reviewer：对 revision diff change 记录 `accepted/rejected/needs_rewrite/needs_evidence`，输出 `revision_diff_reviews.jsonl` 和 `revision_diff_review_summary.json`。
- Metadata Review Workflow：对 metadata field diff 记录 `accept_change/reject_change/needs_verification/request_revert`，输出 `metadata_review_actions.jsonl` 和 `metadata_review_summary.json`。
- PDF Page Review Workflow：对 PDF 页记录 `accepted_as_readable/needs_ocr/ignore_page/needs_manual_check`，输出 `pdf_page_reviews.jsonl` 和 `pdf_page_review_summary.json`，不执行 OCR。
- Analysis Timeline：基于已有 run history 和 analysis comparison 生成 `analysis/analysis_timeline.json`。
- Audit Filter Export：按 audit 分类字段过滤导出 JSON 和 Markdown 报告，输出到 `audit/filtered_exports/`。
- 前端新增 5 个 v0.9 面板，并保持 mock fallback。
- 新增 pytest、Playwright E2E 和 `validate_v09.py`。

## 5. v0.9 仍未完成能力

- 不做真实 OCR，只记录 `needs_ocr` 或 OCR 未配置。
- 不做真实 DOI、作者、年份、期刊、页码联网核验。
- 不自动执行 metadata revert。
- 不自动把 placeholder/extracted 文献变成 verified。
- 不自动证明 revision diff 语义正确，仍需要人工审阅。
- 不做生产级审计、权限、队列、重试或多用户协作。
- 不做真实科研软件接入、真实仪器接入、真实查重或完整 LaTeX 编译。

## 8. 数据结构说明

Revision diff review：
- 输出：`manuscript/revision_diffs/revision_diff_reviews.jsonl`
- 字段：`review_id`、`revision_diff_id`、`change_id`、`human_status`、`reason`、`created_at`、`source`
- summary：`revision_diff_review_summary.json`，统计 reviewed/unreviewed 和各状态计数。

Metadata review workflow：
- 输出：`literature/metadata_review_actions.jsonl`
- 字段：`action_id`、`review_action_id`、`literature_id`、`field`、`action`、`source_history_id`、`reason`、`created_at`、`source`
- 不修改 `literature/literature_index.json`。

PDF page review：
- 输出：`literature/pdf_page_reviews.jsonl`
- 字段：`review_id`、`page_review_id`、`source_file`、`page_number`、`auto_quality_signal`、`human_status`、`reason`、`ocr_attempted=false`
- 不执行 OCR，不生成 OCR 文本。

Analysis timeline：
- 输出：`analysis/analysis_timeline.json`
- 字段：`timeline`、`unlinked_comparisons`、`summary`
- 只读取已有 `runs/run_history.json` 和 `analysis/comparisons/*.json`。

Audit filter export：
- 输出：`audit/filtered_exports/audit_filtered_export_*.json` 和 `audit_filtered_report_*.md`
- 字段：`filters`、`matching_entry_count`、`entries`
- 脱敏 secret、API key 和内部绝对路径。

## 16. v0.9 为什么仍不适合公网生产

- 没有登录、鉴权、多租户、权限隔离或生产级访问控制。
- 本地文件和 SQLite 不适合多人并发、公网暴露或敏感数据托管。
- Audit filter export 是本地报告，不是合规审计系统。
- 人工审阅状态不等于真实科研事实验证。
- 不接真实 OCR、真实 DOI 数据库、真实查重、真实科研软件或真实仪器。
- 不具备生产级任务队列、自动重试、告警、备份和恢复能力。

## 17. v0.10 建议方向

- Evidence claim human review workflow。
- Reviewer issue 到 revision diff review 的闭环状态汇总。
- Metadata review action 的撤销执行预览和冲突检查。
- PDF page text preview 与 page review 联动。
- Analysis timeline 多 comparison 可视化和失败 run 对照。
- Audit filtered export 多条件组合过滤 UI。
- Run history failure case fixture 和恢复建议测试增强。
