# ResearchAgent v0.6 验收报告

## 1. v0.6 状态

ResearchAgent v0.6 已在当前项目中增量完成并通过本地验收。v0.6 基于 v0.5 的安全 manuscript patch 和 versioning 能力继续扩展，重点补齐 patch item 人工编辑、patch 冲突检测、merge preview、manuscript diff、issue resolution provenance 反查，以及 audit export 本地完整性报告。

v0.6 未改变 v0.1-v0.5 的核心 workflow 架构，未引入登录、多租户、数据库、队列、LangGraph、真实 DOI 数据库、真实 OCR、真实查重或公网生产部署能力。

## 2. v0.6 已完成能力

- Patch item 人工编辑：支持编辑 proposed patch item 的 `after` 和 `reason`，并自动重跑 patch safety。
- Patch item safety-check：支持对单个 patch item 手动重跑安全检查。
- Patch item 状态字段：补齐 `item_status`、`manual_edits`、`latest_safety_result`，unsafe item 会标记为 `blocked` 或 `needs_revision`。
- Confirm patch 保护：unsafe、blocked、needs_revision 或 skipped item 不会被应用到 manuscript version。
- Patch conflict 检测：支持检测 `same_sentence`、`same_before_text`、`overlapping_location`、`same_claim`、`unsafe_item`。
- Patch merge preview：先执行 conflict detection，再生成 merge JSON 和 markdown preview；不修改 `draft.md`，不生成 manuscript version。
- Manuscript diff：支持 draft 与 manuscript version 的 diff JSON、diff markdown preview、列表读取和详情读取。
- Issue resolution：基于 patch/version provenance 生成 `reviews/issue_resolution.json`，不做语义层面的“已解决”假设。
- Audit export：支持导出 audit hash chain JSON 和 markdown integrity report，并明确声明这不是生产级不可篡改审计系统。
- 前端详情面板：新增 Patch Item Editor、Patch Conflict、Patch Merge、Manuscript Diff、Issue Resolution、Audit Export 面板。
- Mock fallback：后端不可用时，v0.6 dashboard 入口和面板仍可用 mock 数据渲染。
- Playwright 产物策略：配置 trace/video 仅失败保留，screenshot 仅失败保留，并在 `.gitignore` 忽略测试产物。

## 3. v0.6 未实现能力

- 不做公网生产部署。
- 不做用户登录、多租户权限和生产级鉴权。
- 不接 PostgreSQL、Redis、Celery 或 LangGraph。
- 不做真实 DOI 数据库核验。
- 不做真实 OCR fallback。
- 不做真实查重。
- 不接 MATLAB、Origin、COMSOL、ImageJ 或真实实验仪器。
- 不把 local audit export 伪装为生产级不可篡改审计。
- 不自动把 merge preview 应用为 manuscript version。
- 不绕过 patch safety，也不允许 unsafe patch item 被 confirm 应用。

## 9. 安全边界

- Patch item edit 只允许修改 `after` 和可选 `reason`。
- `before`、`issue_id`、`decision_id`、`related_claim_id`、`section`、`paragraph_index`、`sentence_index` 不允许由编辑 API 修改。
- 编辑 patch item 后必须自动重跑 `patch_safety`。
- `blocked`、`needs_revision`、`skipped` item 不会被 confirm 应用。
- Merge preview 不修改 `manuscript/draft.md`。
- Merge preview 不创建或覆盖 manuscript version。
- Issue resolution 只基于 patch/version provenance，不做语义判定。
- Audit export 不包含 secret、API key 或内部绝对路径。
- Audit integrity report 明确说明不是 production-grade tamper-proof audit system。
- Playwright trace、video、report、test result 产物不会进入版本管理。

## 15. v0.7 建议方向

- Patch merge 人工确认流程：把 safe merge preview 转为受控确认动作。
- Patch conflict 可视化定位：在前端按句子、claim、before 文本聚合冲突。
- Manuscript diff 可视化增强：展示逐句 diff、issue_id、claim_id 和 version lineage。
- Audit export 完整性增强：加入导出清单摘要、文件 hash 清单和更清晰的本地信任边界。
- Issue resolution 人工复核：允许人工标注 provenance 反查结果是否真正解决。
- 更完整的真实后端 Playwright E2E：覆盖 patch item edit、conflict、merge、diff、audit export 的真实 API 流程。
