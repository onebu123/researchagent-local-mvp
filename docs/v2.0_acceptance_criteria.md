# ResearchAgent v2.0 Acceptance Criteria

ResearchAgent v2.0 adds a Research Workspace scaffold for local validation and future deployment planning. It must preserve the local mock fallback and must not require API keys, external network access, PostgreSQL, Redis, auth credentials, or cloud infrastructure for the demo.

## Scope

1. Add a `GET /api/system/production-scaffold` API that reports optional database, queue, auth, container, worker, deployment, and validation scaffold state without exposing secret values.
2. Keep SQLite, inline task execution, disabled auth, and `LLM_MODE=mock` as default local fallback modes.
3. Add optional Dockerfiles and compose profiles for API, web, worker, PostgreSQL, and queue infrastructure.
4. Add a worker scaffold smoke entrypoint that can run without external queue access.
5. Add frontend visibility for the v2.0 Research Workspace scaffold while preserving mock fallback.
6. Add pytest and Playwright coverage for the scaffold API, worker smoke, and frontend fallback.
7. Add `scripts/validate_v2.py`.
8. Update README, AGENTS, user guide, limitation notes, and deployment documentation.
9. Keep validation runnable in no-network demo mode. `npm audit` may degrade only when npm registry access fails; an actual vulnerability report must still fail validation.

## Guardrails

- Do not make PostgreSQL, Redis, auth, cloud services, API keys, or external network access mandatory for local validation.
- Do not commit secrets, credentials, real connection strings, environment files with real values, stack traces, or local absolute paths.
- Do not fabricate DOI, citations, p-values, significance, causal claims, OCR output, verified references, or scientific conclusions.
- Do not claim peer review, compliance, or public production readiness.
- Keep all scaffold status reports limited to configuration presence, fallback mode, and operator caveats.

## Required Validation

```bash
python -m pytest services\api\tests\test_v2_production_scaffold.py
python -m pytest services\api\tests\test_v2_static_contract.py
python -m app.workers.research_worker
python scripts\validate_v2.py
cd apps\web
npm run typecheck
npx playwright test -g "v2.0 Research Workspace scaffold"
```

`ResearchAgent v2.0 validation passed.` must be printed by the v2 validation script.
