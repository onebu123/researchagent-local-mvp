# ResearchAgent v1.1 验收报告

## 已实现

- 后端新增 OpenAI-compatible LLM client，支持 mock/live/fallback、timeout、retry、provider/model/prompt_version 标记。
- 新增 LLM 状态、测试、调用日志、Prompt registry、Literature RAG、source passage evidence、metadata lookup、BibTeX、citation support API。
- 新增本地 RAG 文件：`literature/rag/chunks.jsonl`、`literature/rag/rag_index.json`、`literature/rag/rag_answers.jsonl`。
- 新增 provenance 文件：`provenance/source_passage_evidence.json`、`provenance/citation_support_report.json`。
- 新增文献辅助文件：`literature/metadata_lookup_results.jsonl`、`literature/metadata_lookup_summary.json`、`literature/references.bib`、`literature/bibtex_report.json`。
- 前端新增 Literature Intelligence 分组与 LLM Settings、LLM Call Log、Literature RAG、Source Passage Evidence、Metadata Lookup、BibTeX、Citation Support 面板。
- 新增 pytest v1.1 用例、Playwright v1.1 用例和 `scripts/validate_v11.py`。

## 验收边界

- v1.1 默认使用 mock LLM；live 仅在本地配置 API key 后启用。
- RAG 只检索本地 parsed literature 文本，不联网，不要求 PaperQA2。
- Metadata lookup 默认 mock provider；optional provider 的结果仍需人工验证。
- BibTeX 不为 placeholder/extracted/unverified 记录生成正式引用。
- Citation support 是本地文本支持检查，不证明科学真实性或同行评审通过。

## 验证命令

完整验收应运行：

```bash
python -m compileall services\api scripts
python -m pytest services\api\tests
python scripts\seed_demo.py
python scripts\run_demo.py
python scripts\validate_v1.py
python scripts\validate_v11.py
cd apps\web
npm run typecheck
npm run build
npm audit
npx playwright test
```

本报告不包含真实 DOI 验证、真实 OCR、外部科学数据库验证、生产安全审计或 peer-review-ready 结论。
