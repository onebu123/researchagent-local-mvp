# ResearchAgent v1.3 Acceptance Criteria

v1.3 在 v1.2 Reference Verification 基础上增量实现 RAG Quality & Hybrid Retrieval。目标是让本地 Literature RAG 的 chunk、检索结果和检索评测具备可解释质量信号；不是接入公网向量数据库、真实 embedding 服务或生产级 RAG 平台。

## Scope

- 保留 v1.0-v1.2 validation、mock fallback、无 API key、无外部网络 demo。
- 新增本地 hybrid retrieval：keyword token overlap + local character n-gram similarity + metadata trust signal。
- 新增 chunk quality report，标记 empty/short/low lexical diversity/placeholder metadata/low text quality 风险。
- 新增 retrieval eval set 和 eval report，使用本地 deterministic fixtures，不依赖外部模型。
- RAG answer 记录必须包含 retrieval_mode、hybrid score breakdown、quality warnings。
- 前端新增 RAG Quality 面板，展示 chunk quality、eval metrics、hybrid retrieval preview。
- 文档说明 v1.3 不声称 scientific proof、peer-review-ready、production-ready 或真实向量召回质量。

## API Acceptance

- `POST /api/projects/{project_id}/literature/rag/build` keeps working and reports `retrieval_mode=local_hybrid`.
- `POST /api/projects/{project_id}/literature/rag/ask` accepts `retrieval_mode=local_hybrid|local_keyword` and returns source passages with score breakdown.
- `GET /api/projects/{project_id}/literature/rag/quality` returns chunk quality report.
- `GET /api/projects/{project_id}/literature/rag/eval-set` returns local eval cases.
- `POST /api/projects/{project_id}/literature/rag/evaluate` generates eval report.
- `GET /api/projects/{project_id}/literature/rag/evaluation` returns latest eval report or generates one.

## Safety Acceptance

- No external network is required.
- No API key, secret, full prompt, or internal absolute path is written to logs or reports.
- Placeholder metadata reduces trust and cannot create strong citation or reference claims.
- Retrieval scores are heuristic and must not be presented as scientific proof.
- Validation must pass:
  - `python scripts/validate_v1.py`
  - `python scripts/validate_v11.py`
  - `python scripts/validate_v12.py`
  - `python scripts/validate_v13.py`
  - `python -m pytest services/api/tests`
  - `npm run typecheck`
  - `npm run build`
  - `npm audit`
  - `npx playwright test`
