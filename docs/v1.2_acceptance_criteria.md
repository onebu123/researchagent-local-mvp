# ResearchAgent v1.2 验收标准

v1.2 的目标是在 v1.1 Literature Intelligence 基础上，新增可人工确认的引用核验链路。v1.2 不重写架构，不引入公网生产、多租户、登录、Redis、Celery、PostgreSQL、LangGraph、PaperQA2、真实 OCR 或科研仪器集成。

## 必须保持的基线

- `python scripts/validate_v1.py` 必须继续通过。
- `python scripts/validate_v11.py` 必须继续通过。
- v0.1-v0.10 validation 脚本必须保留。
- v1.1 的 LLM mock/live/fallback、Prompt Registry、LLM Call Logging、Literature RAG、Source Passage Evidence、Metadata Lookup、BibTeX Draft、Citation Support 和前端 Literature Intelligence UI 必须继续可用。
- 无 API key、无外网依赖时，demo 和 validation 必须通过。

## Reference Verification

- 新增 `services/api/app/tools/reference_verification.py`。
- 生成 `literature/reference_verification/reference_verification_results.jsonl`。
- 生成 `literature/reference_verification/reference_verification_summary.json`。
- `mock_fixture` provider 必须默认可用。
- optional providers 失败时必须 graceful，记录 `provider_failed`，不得导致 workflow 崩溃。
- verification 只生成 candidate，不得自动修改 `literature_index.json`，不得自动标记 verified。
- 每条 result 必须包含 `match_scores`，所有 score 必须在 0.0 到 1.0。

## Match Score

- 新增 `services/api/app/tools/reference_match_score.py`。
- 计算 title、author、year、DOI、journal 和 overall confidence。
- DOI exact match 是强信号，DOI mismatch 必须降低 confidence。
- 缺失数据不能抛异常，也不能给高 confidence。

## Reference Approval

- 新增 `services/api/app/tools/reference_approval.py`。
- 生成 `literature/reference_approvals.jsonl`。
- 生成 `literature/reference_approval_summary.json`。
- 默认 `apply_to_literature_index=false`，只写 approval log，不改索引。
- 只有 `decision=approved` 且 `apply_to_literature_index=true` 时，才允许把 candidate 写入 `literature_index.json`。
- apply 时必须写 `literature/metadata_history.jsonl` 和 `audit/audit_log.jsonl`。
- rejected / needs_manual_check 不得进入 verified references。

## Citation Grounding

- 新增 `services/api/app/tools/citation_grounding.py`。
- 生成 `provenance/citation_grounding_report.json`。
- 每条 item 必须绑定 `claim_id` 和 `candidate_chunk_id`。
- placeholder metadata、low quality PDF passage、number mismatch 不得标记为 `strong`。
- grounding strength 是启发式证据，不得声明科学事实已被证明。

## Manuscript References

- 新增 `services/api/app/tools/manuscript_references.py`。
- 生成 `manuscript/references_status.json`。
- 生成 `manuscript/references_section_preview.md`。
- 正式 References 只来自 approved + human_verified + verified metadata。
- Candidate 和 placeholder records 必须分开列出，不得写入正式 References。
- 不得覆盖 `manuscript/draft.md`。

## BibTeX Upgrade

- 扩展 `services/api/app/tools/bibtex_generator.py`。
- 正式 BibTeX entry 只来自 `metadata_status=verified`、`human_verified=true`、`reference_verification_status=approved` 的记录。
- candidate / placeholder / rejected 只进入 comments 或 warnings。
- `bibtex_report.json` 必须包含 approved、candidate、rejected、placeholder 计数。
- 不得伪造 DOI、作者、年份、期刊或页码。

## API

- `POST /api/projects/{project_id}/literature/reference-verification/run`
- `GET /api/projects/{project_id}/literature/reference-verification/results`
- `GET /api/projects/{project_id}/literature/reference-verification/summary`
- `POST /api/projects/{project_id}/literature/reference-verification/{verification_id}/approval`
- `GET /api/projects/{project_id}/literature/reference-approvals`
- `GET /api/projects/{project_id}/literature/reference-approval-summary`
- `GET /api/projects/{project_id}/provenance/citation-grounding`
- `GET /api/projects/{project_id}/manuscript/references/status`
- `GET /api/projects/{project_id}/manuscript/references/preview`

## Frontend

- 新增 Reference Verification 模块。
- 新增 `ReferenceVerificationPanel`、`ReferenceApprovalPanel`、`CitationGroundingPanel`、`VerifiedReferencesPanel`。
- Metadata Lookup、BibTeX、Citation Support、Global Trust 面板必须展示 v1.2 入口或阻断状态。
- 前端不得显示 API key，不得把 candidate 显示为 verified。

## Validation

- 新增 `scripts/validate_v12.py`。
- `validate_v12.py` 必须调用 v1 和 v1.1 validation。
- 必须检查 reference verification、approval workflow、manuscript references、BibTeX upgrade、citation grounding、secret safety。
- 成功输出：`ResearchAgent v1.2 validation passed.`
