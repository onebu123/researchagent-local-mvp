# ResearchAgent v1.3 Acceptance Report

v1.3 已完成 RAG Quality & Hybrid Retrieval 增量实现。实现保持本地 MVP 边界：默认 `local_hybrid`，无 API key、无外部网络依赖，不引入真实向量数据库、embedding 服务、PaperQA2 强依赖、生产部署或 peer-review-ready 声明。

## Completed

- 本地 hybrid retrieval：`services/api/app/tools/literature_rag.py`
  - `keyword_score`
  - `ngram_score`
  - `metadata_trust_score`
  - `quality_score`
  - `matched_terms`
  - `quality_warnings`
- RAG quality report：`services/api/app/tools/rag_quality.py`
  - `literature/rag/chunk_quality_report.json`
  - `literature/rag/retrieval_eval_set.json`
  - `literature/rag/retrieval_eval_report.json`
- API：
  - `GET /api/projects/{project_id}/literature/rag/quality`
  - `GET /api/projects/{project_id}/literature/rag/eval-set`
  - `POST /api/projects/{project_id}/literature/rag/evaluate`
  - `GET /api/projects/{project_id}/literature/rag/evaluation`
- Frontend：
  - `apps/web/components/RAGQualityPanel.tsx`
  - dashboard `RAG Quality` entry
  - mock fallback in `apps/web/lib/api.ts`
- Tests:
  - `services/api/tests/test_v13_hybrid_retrieval.py`
  - `services/api/tests/test_v13_rag_quality.py`
  - `services/api/tests/test_v13_no_network_required.py`
  - `apps/web/e2e/v13-rag-quality.spec.ts`
- Validation:
  - `scripts/validate_v13.py`

## Not Completed By Design

- No external vector database.
- No external embedding provider.
- No PaperQA2 hard dependency.
- No production RAG benchmark claim.
- No scientific proof, citation truth, DOI verification, p-value, statistical significance, causal inference, production-ready, compliance-ready, or peer-review-ready claim.

## Safety Notes

- `local_keyword` remains supported as fallback.
- Placeholder metadata reduces metadata trust and adds warnings.
- RAG answer source passages include score breakdown and limitations.
- Retrieval eval cases are local deterministic smoke checks only.
- No API key or external network is required for v1.3 demo or validation.

## Validation Evidence

The stage validation entry point is:

```bash
python scripts/validate_v13.py
```

It checks v1.2 validation, v1.3 files, demo outputs, API contracts, frontend markers, and safety documentation markers.
